# BuildFlow Master Plan

## Product goal
Enable a five-person SaaS team to describe an entire application as a structured script and deliver it section by section, even when developers work asynchronously.

## Primary users
Project Owner; Developer; Designer/Content; Finance Reviewer; QA/Security Reviewer.

## MVP outcomes
1. Create a project and invite members.
2. Describe modules, pages, sections and features in a structured hierarchy.
3. Store rich specifications with acceptance criteria and version history.
4. Convert a section into one or more assigned development tasks.
5. Claim tasks without two developers accidentally owning the same work.
6. Track PRs, review, testing, bugs, and completion.
7. See progress by module, page and project.
8. Copy a task-specific AI coding prompt.

## Out of scope for MVP
Automatic AI coding, automatic PR creation, real-time GitHub sync, billing, time tracking, advanced reporting.

## Success criteria
A new developer can select a ready task, understand its scope and dependencies, implement it, and hand it off without needing an earlier AI chat.

## Product decisions to confirm
Single organization or multiple organizations? GitHub integration in MVP or manual PR links? Rich-text collaboration requirements? Attachment storage limits?
