# Module 05 — QA and Bugs

## Page: QA Queue `/projects/:projectId/qa`
Sections: tasks awaiting verification; test checklist; tester assignment.
Actions: pass/fail test cases; record evidence; accept or reject.
Acceptance: rejected task returns to implementation with explanation.

## Page: Bugs `/projects/:projectId/bugs`
Sections: severity filters, open/resolved counts, bug list.
Actions: report bug with expected/actual results, reproduction steps, environment and screenshots; assign and retest.
Acceptance: bug links to relevant task/section, audit trail preserved, resolved bugs require retest.
